站点

只影响面板与 Caddy 的对外行为
改成别的端口后，隧道的上游也要一起改

维护模式

打开后整站返回 503，隧道和规则都不用动

安全

IP 黑名单最先匹配；限流需要自定义 Caddy 镜像
只在 `CADDY_RATELIMIT=1` + xcaddy 自定义镜像时生效，见 docs/RATELIMIT.md

掉线通知

出口掉线 / 换域名 / Caddy 下发失败时推一条
机器人安全设置里勾了「加签」才需要；只勾「自定义关键词」就留空
比如出口掉线后 5 分钟内只提醒一次，避免反复刷屏；0 = 不冷却
这段时间内不发通知（可跨零点，多段用逗号：12:00-13:30,23:00-07:00）
占位符：{event} {title} {text} {host} {time} {running} {total}
例：{time}｜{host}｜在线 {running}/{total}

面板登录

设置后浏览器会弹 HTTP Basic 登录框

登录会话

谁在什么设备上登录着，可以逐个踢掉
一个会话 = 一次登录：7 天免密、12 小时不动就失效。踢掉后那台设备需要重新登录。同一会话换了来源 IP 会打「换过 IP」标记并推一条通知（改面板口令会自动踢掉所有会话）。
账号角色来源 IP设备登录时间最后活动

只读账号

给「只想看看状态」的人：能看所有页面，改不了任何配置
只读账号用浏览器 Basic 登录，GET 一律放行、写操作返回 403。首次设置必须同时给密码。

二次验证（TOTP）

手机验证器 App 的 6 位数字，登录时多一道关
开启后，浏览器登录要先输口令、再输验证器里的 6 位数字。curl / 脚本仍可用 Basic（当作机器凭证），所以别把账号口令写进公共脚本。
用 Google Authenticator / 1Password / Authy 扫码
这些恢复码只显示这一次，请立刻抄到安全的地方（每张纸只能救一次命）。
